# Finance Multi-Tool

A simple console application written in Python to manage currency conversion and track saving goals. Built as a personal project to practice programming logic, loops, and conditional structures.

## Features
* **Currency Converter:** Converts USD amounts into Kazakhstani Tenge (KZT) and Russian Rubles (RUB) using fixed exchange rates.
* **Saving Goal Calculator:** Calculates how many months it will take to achieve a specific financial goal based on your monthly savings.
* **Continuous Execution:** The program runs continuously in an infinite loop until you choose to exit.

## Technologies Used
* Python 3
* Infinite `while` loops and control flow structures (`if/elif/else`)
* Type casting (`float()`) and formatted string literals (f-strings)

## How to Run
1. Open your terminal or IDE.
2. Run the script:
   ```bash
   python main.py
   ```
3. Follow the on-screen menu instructions.
